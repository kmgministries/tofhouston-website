Connect the private database

The portal code is on your church website. Its database must be initialized by the Supabase project owner before accounts can work.

  1. Open your Results Matter project in the Supabase dashboard.
  2. Open SQL Editor → New query.
  3. Copy the setup SQL below, paste it into the editor, and choose Run. Run the setup only once.
  4. Open Authentication → URL Configuration. Set the Site URL to https://tofhouston.org/results-matter/ and add that same URL to the allowed redirect URLs.
  5. Return to the portal and choose Request account. Confirm your email if prompted.
  6. Enter the email you used below to prepare the administrator activation query. Run that query in the SQL Editor.
  7. Sign in to the portal. Use Administration to activate approved staff and residents. Link each resident login to that resident’s profile.

1. Database setup

The SQL creates tables, server-side access rules, a private document bucket, and audit history. It does not insert real resident information.

2. Activate your administrator account

This must match the confirmed account you requested on the portal. No account is automatically made an administrator.

Before entering real resident information

Test with clearly marked demo records and separate staff and resident accounts. Verify that residents cannot see other residents, staff notes, incidents, or administration. Confirm document permissions and your account recovery process.

This is the initial portal release. Recurrence fields currently record the intended schedule; they do not automatically create repeated events. SMS, payment processing, email notifications, scheduled aftercare, and native Excel exports require additional implementation. Account reset and confirmation email delivery depends on Supabase’s configured email service. Remember-me token storage is intentionally disabled.
